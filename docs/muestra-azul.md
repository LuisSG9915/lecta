# Libro de muestra: «Azul…» de Rubén Darío

`public/libros/azul-ruben-dario.epub` se incluye con la app para que una
estantería vacía pueda ofrecer lectura de inmediato («Leer un libro de
muestra» en la estantería).

- **Texto**: «Azul...», Rubén Darío (1916 — dominio público en todo el
  mundo, incluido México).
- **Fuente del EPUB**: Wikisource en español
  (<https://es.wikisource.org/wiki/Azul...>), generado con
  [WS-Export](https://ws-export.wmcloud.org/). El contenido de
  Wikisource se publica bajo CC BY-SA 3.0 + GFDL; el colofón va dentro
  del propio EPUB (`OPS/about.xhtml`) y cumple la atribución.
- **Edición local**: solo se quitó el prefijo «Autor:» de
  `dc:creator`/`dc:contributor` en `OPS/content.opf` para que la
  estantería muestre «Rubén Darío».
- **Ojo**: la edición de Project Gutenberg del mismo libro (ebook
  52894) lleva ilustraciones de Enrique Estévez Ochoa que podrían
  seguir protegidas en México; por eso se eligió la edición de
  Wikisource, que también las lista pero es la fuente limpia elegida.
